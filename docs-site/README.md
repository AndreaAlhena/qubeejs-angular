# Documentation site

The `@qubeejs/angular` docs, built with [Docusaurus](https://docusaurus.io/). The API reference under `docs/api` is generated by TypeDoc from `../src/public-api.ts` on every build and is not committed.

## Setup

Install the library's dependencies first — TypeDoc resolves `@angular/core` and `@qubeejs/core` from the root `node_modules` — then the site's own:

```bash
npm ci            # in the repository root
cd docs-site
npm ci
```

## Local development

```bash
npm start
```

Starts a dev server with live reload. The "next" docs (the `docs/` folder) serve at `/docs/next/`; the latest snapshot in `versions.json` serves at `/docs/`.

## Build

```bash
npm run build
```

Generates the static site into `build/`, TypeDoc pages included. `onBrokenLinks` is set to `throw`, so a dangling relative link fails the build.

## Releasing a version

The release commit snapshots the current docs under the new version number:

```bash
npx docusaurus docs:version 4.0.0
```

## Deployment

Pushes to `master` that touch `docs-site/**` or `src/**` deploy through `.github/workflows/docs.yml` to GitHub Pages.
